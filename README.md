# atividade-pratica-4
Dashboard analítico em Power BI que integra dados fictícios de produção, qualidade e manutenção. Inclui ETL no Power Query, medidas em DAX, cartões de KPI, gráficos de linhas e barras e segmentadores de Período, Máquina e Turno para monitorar metas, defeitos e paradas de máquina.
